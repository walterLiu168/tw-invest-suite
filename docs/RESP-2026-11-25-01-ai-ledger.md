## §0 這頁回答什麼

**「AI 自己的策略，模擬買賣到現在，賺了還是賠了？」**

這不是裝飾頁。Walter 要拿這個帳戶的模擬交易去實際下單、並用它支付服務費，
所以規則寫死、版本化、印在頁面上，帳本 append-only，每一筆都帶當時的規則版本與決策依據。

## §1 規則（AIV1）

| | 規則 |
|---|---|
| R1 | 每個交易日在收盤後做決策，買賣成交價一律為當日收盤價 |
| R2 | 進場池＝當日已發佈的 24 檔精選，只做 long；short 僅記為「當日迴避」 |
| R3 | 同時最多 6 檔、等權、不對既有部位加碼 |
| R4 | 每檔每交易日最多一筆交易（買或賣），當日已賣不當日買回 |
| R5 | 出場（先到先算）：跌出 24 檔／維持率破 130%／持有滿 20 個交易日／自成本價 −12% |
| R6 | 成本：買賣各手續費 0.1425%（最低 20 元）、賣出證交稅 0.3% |
| R7 | 現金會計：部位成本含攤提費用，每日以收盤價重估 |
| R8 | 基準＝同一批交易日的等權全市場（與危險頁同一套方法） |
| R9 | 判定線：滾動 20 個交易日，淨報酬 > 0 且超額 > 0 且最大回撤 < 25%；連續 3 個週期不達線 → 停止新進場 |

「一天一檔一筆」是 Walter 指定的：同一檔當天不重複交易，賣出優先於買進。

## §2 回溯基線（2026-08-12 → 11-24，56 個交易日、99 筆交易）

| 指標 | 值 |
|---|---|
| 權益 | 1,000,000 → **828,129** |
| 淨報酬 | **−17.19%** |
| 等權全市場同期 | −26.05% |
| **超額** | **+8.86pp** |
| 最大回撤 | −33.63% |
| 滾動 20 日通過率 | 10/37 個區間（27%）|
| 期末部位 | 5 檔 |

**判定：未通過（no_edge）** —— 超額是正的，但淨報酬為負、最大回撤 −33.6% 也超過 25% 的門檻。

### 這個數字怎麼讀

三件事同時成立：

1. **策略在相對意義上有價值**：同期市場跌 26%，帳戶只跌 17%，贏 8.86pp。
2. **策略在絕對意義上沒有存活**：跌 17% 就不是「能拿來付費」的帳戶。
3. **edge 來自出場紀律，不是進場訊號**：同一段期間，模型原始的 ADD 呼叫是 **−2.13pp（5 日）／−3.31pp（10 日）**，
   加上這套出場規則後變成 **+8.86pp** → **值錢的是「何時賣」，不是「買什麼」**。

出場次數統計：跌出 24 檔 36 次、停損 8 次、20 日到期 2 次、危險規則 1 次
→ **主要是「跌出精選」在賣**（跌出 24 檔 = 隔天才知道，所以實際會多持有一天）。

### 誠實的限制

- **回溯段含事後偏差**：規則是看過這段資料之後定的。頁面把 2026-11-25 之前標成「回溯」，
  之後才是乾淨的前瞻紀錄。
- **樣本小且全在崩盤裡**：可用期間 56 個交易日，市場同期跌 26%。
- **模型的期限（20 日）在回溯段幾乎沒有已結算資料** → 「AI 自己的期限有沒有效」要靠 live 紀錄回答。

## §4 誠實揭露

- **「收盤價成交」是紙上慣例**：收盤價在 13:30 集合競價結束後才確定。若實際下單，
  真實成交是次一交易日開盤價 → 帳本已預留「實際成交」欄位（R10），兩邊差異看得見。
- **空單不計損益**：台股個股幾乎不能做空，short 只記為「當日迴避」。
- **手續費假設 0.1425%**：實際依券商折扣與最低 20 元而異。
- **這頁不是績效保證**，是帳本的自我審計——它必須能顯示自己沒有鑑別力。

## §5 對「拿來付費」的意義

帳戶在唯一有結果的視窗裡虧了 17%。若當時照著模擬單實際下單，這個帳戶會付不出服務費。
因此 R9 的判定線用**絕對淨報酬**（不是超額），且連續 3 個週期不達線就停止新進場。
live 紀錄從 2026-11-25 起累積——那才是能拿來付費的證據。
